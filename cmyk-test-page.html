CMYK Test Page

Check cyan, magenta, yellow and black separately and find which cartridge is failing.

Preview matches the printout. In the print dialog set scale to 100% and enable "Background graphics" for accurate color. Screen colors are RGB; your driver converts them to ink, so this checks your printer, not true CMYK values.

What CMYK means

CMYK stands for Cyan, Magenta, Yellow and Key (black), the four inks used by most color printers. Each should print as a solid, vivid block.

Important accuracy note

Web pages cannot send true CMYK values. This page is drawn in RGB and converted by your printer driver. It is reliable for spotting a faded or blocked ink, but not for exact color matching or professional proofing.

Pinpointing the failing ink

  • Faded cyan: cyan cartridge low, and greens and blues look off.
  • Faded magenta: reds and pinks look weak.
  • Faded yellow: oranges and greens look cold.
  • Weak black: text looks gray.

FAQ

Is this a real CMYK test?

It checks your printer's four inks in practice, but the page itself is RGB because browsers cannot output CMYK. Use a print-shop PDF for professional proofing.

Which test should I use for clogged nozzles?

Use the Streak check tab, then run your printer's own nozzle check from its Maintenance menu.
